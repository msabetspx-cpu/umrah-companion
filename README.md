# رفيق العمرة — Umrah Companion

مساعد شخصي **يعمل دون إنترنت بالكامل** يرافقك خطوة بخطوة أثناء أداء العمرة.
تطبيق ويب (PWA) بتقنية HTML/CSS/JavaScript خالص — بلا أي framework أو مكتبات خارجية أو استدعاءات إنترنت.

## الميزات
- **رافقني**: رحلة من 11 مرحلة (الاستعداد → الميقات → الإحرام → التلبية → الوصول → الطواف → بعد الطواف → السعي → بعد السعي → التحلل → تمّت العمرة) مع السماح بالرجوع لأي مرحلة.
- **الرئيسية**: تعرض «المرحلة الحالية» حيّة (مثال: الطواف — الشوط 4 من 7).
- **ماذا أفعل الآن؟** إجابة سياقية تعرف شوطك الحالي وذكره، وتنبّه أنه لا دعاء مخصوص لأي شوط.
- **عدّاد الطواف والسعي**: عرض بالشوط الحالي + نقاط تقدّم + تراجع/إيقاف/إعادة بتأكيد + حارس ضغط سريع + حفظ فوري.
- **أنا اتلخبطت**: حالات شائعة (شك بالعدد، الوضوء، التعب، التحلل...) بإجابات موثقة، ومع غياب الدليل: إحالة لأهل العلم.
- **وضع الزحام**: خط وأزرار أكبر وإخفاء التفاصيل الثانوية.
- **الأذكار والمحظورات والمصادر**: بنموذج بيانات موحّد (مصدر/درجة/رقم/رابط/تاريخ تحقق)، وفصل المصادر الشرعية عن الرسمية.
- **قبل السفر**: checklist بأقسام قابلة للتعديل. **معلومات رحلتي**: محلية فقط لا تُرسل لأي خادم.
- **الوضع الليلي**، بحث عربي مع تطبيع، وواجهة RTL Mobile-First مع دعم safe-area في iPhone.

## الأولوية الشرعية
كل محتوى ديني له مصدر ودرجة. لا يُخصَّص دعاء لشوط، ولا يُنسب حكم للتطبيق، وكل مسألة خلافية تُعرض بخلافها ومصدرها. ما يحتاج فتوى يُحال لأهل العلم. راجع `RELIGIOUS_AUDIT.md` و`CONTENT_AUDIT.md`.

## التشغيل
التطبيق PWA (يحتاج عامل خدمة)، فيجب تقديمه عبر HTTP (لا يعمل من `file://`):
```bash
python3 -m http.server 8000    # ثم افتح http://localhost:8000
```
منشور على GitHub Pages: افتحه أونلاين مرة واحدة كاملة ليُخزَّن، ثم يعمل دون إنترنت.

## لا اعتماديات خارجية
لا CDN، لا Google Fonts، لا JS/CSS/صور خارجية، لا API، لا analytics. روابط المصادر اختيارية وموسومة «تحتاج إنترنت».

## الملفات
`index.html` · `styles.css` · `app.js` · `sw.js` · `manifest.json` · التقارير (`AUDIT_REPORT`, `RELIGIOUS_AUDIT`, `CONTENT_AUDIT`, `TECHNICAL_AUDIT`) · `tests/browser-test.mjs`.
