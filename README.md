# رفيق العمرة — Umrah Companion

تطبيق ويب (PWA) يعمل **دون إنترنت بالكامل** لإرشاد المستخدم خطوة بخطوة أثناء أداء العمرة:
خطوات العمرة، وضع «رافقني»، عدّاد الطواف، عدّاد السعي، الأدعية والأذكار الثابتة،
محظورات الإحرام، «ماذا أفعل الآن؟»، «نسيت ماذا أفعل؟»، قائمة التجهيزات، الوضع الليلي.

## التشغيل
لأن التطبيق PWA (يحتاج عامل خدمة)، يجب تقديمه عبر خادم HTTP (لا يعمل عامل الخدمة من `file://`):

```bash
cd umrah_companion
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

بعد أول تحميل يُخزَّن كل شيء ويعمل التطبيق دون إنترنت (جرّب: أغلق الشبكة وأعد التحميل).

## لا اعتماديات خارجية
لا CDN، لا Google Fonts، لا استدعاءات API. كل الملفات محلية. روابط المصادر
(dorar / islamqa) اختيارية وموسومة بأنها «تحتاج إنترنت» ولا يعتمد عليها عمل التطبيق.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | الهيكل والواجهة (RTL، Mobile First) |
| `styles.css` | التنسيقات + الوضع الليلي + حالات التركيز |
| `app.js` | المنطق: الحالة، العدّادات، آلة الحالة، البيانات الشرعية، الأمان |
| `sw.js` | عامل الخدمة (كاش + عمل Offline) |
| `manifest.json` | بيان PWA |
| `AUDIT_REPORT.md` | تقرير المراجعة الكامل وجدول الإصلاحات |
| `RELIGIOUS_AUDIT.md` | التدقيق الشرعي (مصدر ودرجة كل نص) |
| `SOURCE_AUDIT.md` / `RELIGIOUS_CONTENT_AUDIT.md` | تدقيق المصادر الأصلي |
| `tests/browser-test.mjs` | اختبارات المتصفح الآلية (Playwright) |

تتطلب Playwright و Chromium. من داخل المجلد:
```bash
node tests/browser-test.mjs
```
(يشغّل خادماً مؤقتاً ويقود متصفحاً حقيقياً، ويختبر أيضاً العمل دون إنترنت بإيقاف الخادم.)
